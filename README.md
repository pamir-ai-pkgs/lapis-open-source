# Lapis open-source materials

Source code and license notices for selected open-source components distributed with Lapis products.

## Lapis App

| App version | Component sources and notices |
| --- | --- |
| 1.5.19 | [WebRTC source release](https://github.com/pamir-ai-pkgs/lapis-open-source/releases/tag/app-v1.5.19-oss-59ef7f88850c) |

Download the attached `gstwebrtc-api-3.0.0-lapis-source.tar.gz` under **Assets**, extract it and follow `README-LAPIS.md` to build and test the library. It includes the modified library source, type declarations, tests, build configuration, original README and MPL 2.0 license.

- `THIRD-PARTY-NOTICES.txt` contains license and copyright notices for gstwebrtc-api, webrtc-adapter and sdp.
- `open-source.json` records component versions, upstream archive identities and source-file hashes.
- `SHA256SUMS` records checksums for the downloadable materials.

GitHub's automatically generated **Source code (zip/tar.gz)** downloads contain only this repository's index; use the named library archive above. Downloads are public and do not require a GitHub account. License notices are also bundled in App versions with the Open-source licenses screen.

These releases cover the listed components; they are not App installers or an inventory of every App or device dependency. A source release does not announce an App rollout. Device operating-system sources are not currently included here.

## Licenses and retention

Each component retains its own license and copyright notices. Lapis modifications to gstwebrtc-api are supplied under MPL 2.0. Other components are not relicensed under MPL. No single repository-wide license replaces these component licenses.

Keep versioned source releases available and do not overwrite their assets. A changed component set receives a new source revision.

This repository does not contain Lapis's proprietary App implementation, private build infrastructure or credentials.
