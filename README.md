# LAPIS Open Source

This repository provides source code, license notices, and related
materials for open-source software used in LAPIS products.

Source packages are available in [Releases](https://github.com/pamir-ai-pkgs/lapis-open-source/releases).
See each release for component versions, applicable product versions,
and accompanying documentation.

Please refer to the license and copyright notices included with
the source materials.
